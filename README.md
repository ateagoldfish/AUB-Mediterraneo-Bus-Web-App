# AUB Mediterraneo Bus Web App

A simple website for AUB Mediterraneo students: the shuttle bus timetable, current delays/changes, and the bus's live
location on a map — all in one place, instead of scattered across emails.

University semester project (Industrial Engineering), due 1 December 2026.
